# SoundCloud Client — стеклянный неофициальный клиент для Windows

Тёмный десктоп-плеер на Python + PySide6: полупрозрачное «стекло» с акриловым
размытием через DWM, поиск по трекам, артистам и плейлистам, очередь
воспроизведения, полноэкранный плеер с cava-визуализатором, локальные лайки.

> ⚠️ **Дисклеймер:** неофициальный проект, не связанный со SoundCloud Ltd.
> Название «SoundCloud» используется только для описания совместимости сервиса.
> Использует неофициальный web-API `api-v2.soundcloud.com` поверх публичного
> аудиостриминга SoundCloud. Всё для личного, некоммерческого использования.

## Возможности

- 🔍 Поиск по трекам / артистам / плейлистам (вкладки)
- 🎧 Воспроизведение с очередью: клик по треку — играем и всё ниже в очередь
- 👤 Страницы артистов и плейлистов (официальная статистика, топ-треки, альбомы)
- ❤️ Локальная «Медиатека» (без входа в аккаунт): лайки живут в JSON
- ↺ «Недавно прослушанные» + кнопка «Очистить историю»
- 🪟 Полупрозрачное окно с размытием обоев (DWM), без синевы
- ⛶ Полноэкранный плеер: круглая обложка, cava-визуализатор, громкость
- 🚀 Ничего лишнего: без рекламы, без аккаунтов, без скачивания треков

## Установка

### 1. Python

Нужен Python **3.10 или новее** (проверено на 3.12). Если его нет:

1. Скачай с [python.org/downloads](https://www.python.org/downloads/)
2. При установке **обязательно** поставь галочку **«Add python.exe to PATH»**
3. Проверь в консоли: `python --version`

### 2. Клонирование репозитория

```bat
git clone https://github.com/RaHd0m/soundcloud-client.git
cd soundcloud-client
```

(если git не установлен — [git-scm.com](https://git-scm.com/download/win),
или просто скачай репозиторий ZIP-ом и распакуй)

### 3. Зависимости

```bat
pip install -r requirements.txt
```

Поставятся `PySide6` (Qt 6) и `requests`. Больше ничего не нужно.

### 4. Запуск

```bat
python main.py
```

или двойным щелчком по `run.bat`.

Хочешь красивый ярлык — создай ярлык на `run.bat` на рабочем столе
(ПКМ → Отправить → Рабочий стол) и поменяй у него иконку на `icon.ico`.

### 5. (Windows 11) Включи «Эффекты прозрачности»

В противном случае Windows рисует все акриловые фоны серой болванкой, и
«стекло» не будет видно:
**Параметры → Персонализация → Цвета → Эффекты прозрачности → ВКЛ.**
Приложение само подскажет при запуске из консоли, если эффект выключен.

## Как пользоваться

- **Поиск** — строка сверху (Ctrl+F), Enter. Вкладки: Треки / Артисты / Плейлисты.
- **Трек** — двойной клик по строке. Очередь формируется из открытого списка.
- **Сердечко** — сохраняет трек в «Медиатеку» (в строке трека или внизу окна). Лайки и «Недавно» хранятся локально в `%APPDATA%\SCClient\library.json`.
- **Пробел** — пауза/плей, клик по полосе — перемотка, слайдер справа — громкость.
- **⟳ Повтор** (рядом с «следующий») — три режима по клику: выкл → повторять
  всю очередь → повторять один трек (иконка с цифрой «1»). Режим сохраняется
  между запусками.
- **◀** — вернуться на предыдущую страницу.
- **⤢** (в панели плеера) — большой плеер на всё окно (внутри: ⛶ — разворот на весь экран, Esc/✕ — назад). Нижняя панель при этом скрывается, чтобы иконки не дублировались.
- **↺ Недавно → «Очистить историю»** — удалить всю историю прослушиваний.

## Внешний вид: стекло и блюр

Окно без собственной краски — сквозь него видно только **размытые обои**
(DWM BlurBehind, нейтральное стекло без синевы). Блюр включён всегда.
Порядок подбора фона (`window_effects.py`), проверен пиксельным
сэмплированием на Win11 24H2+:

1. **BlurBehind** (`DwmEnableBlurBehindWindow`) — основной режим;
2. DWM System Backdrop (акрил/Mica, Win11 22H2+) — фолбэк;
3. Легаси-акрил `SetWindowCompositionAttribute` (Win10);
4. Если ничего не сработало — окно непрозрачное (без «чёрного дыра»).
   Чистый Mica не используется как основной режим: на части сборок он
   рисует непрозрачный сине-серый пласт вместо стекла.

Панели (сайдбар, плеер) рисуются своим `GLASS_PANEL` для читаемости; интенсивность краски крутится константами `GLASS_ROOT` / `GLASS_PANEL` в `theme.py`.

## Анимации

- Страницы при переходе (вперёд/назад) проявляются (250 мс) и мягко
  «въезжают» снизу на 14px (OutCubic).
- Нижняя панель плеера плавно растворяется при открытии полноэкранного плеера
  и так же плавно возвращается (150 мс).
- Cava-визуализатор в полноэкранном плеере «дышит» в такт воспроизведению.

## Закругления

Острых углов нет нигде: панели (сайдбар, нижний плеер) — плавающие карточки
с радиусом 26px и отступом 10px от краёв; строки треков — 20px, кнопки —
капсулы, play — круг, обложки/аватары — круги. Углы самого окна скругляет
DWM (`DWMWA_WINDOW_CORNER_PREFERENCE = ROUND`).

## Большой плеер

Кнопка **⤢** в панели плеера внизу открывает плеер на всё окно: большая
круглая обложка, крупный заголовок, cava-визуализатор, управление, перемотка
и слайдер громкости. Внутри: **⛶** — на весь экран (Esc возвращает окно),
**✕** или Esc — назад в приложение. Нижняя панель скрыта автоматически.

## Иконки

- Иконки плеера (play/pause/prev/next, сердечко, expand/close, громкость,
  корзина) — **векторные**, рисуются в `appicons.py` через QPainter, кэшируются.
- `make_icon.py` — перегенерирует `icon.ico` (тёмный квадрат и оранжевое
  облако); той же иконкой подписывается окно приложения.
- В панели задач приложение регистрирует собственный `AppUserModelID`
  (`SoundCloudClient.Client.1`), поэтому иконка приложения видна вместо
  python-ежа.

## Как это работает (важно)

- SoundCloud закрыл публичный API, поэтому клиент использует **неофициальный
  web-API** (`api-v2.soundcloud.com`): при старте с фронтенда soundcloud.com
  добывается публичный `client_id` и кэшируется в `%APPDATA%\SCClient\client_id.json`.
- Аудио берётся из официальных транскодингов (mp3/HLS). Треки, доступные
  только по подписке go+, проигрываться не будут — появится сообщение об
  ошибке в плеере.
- Проверка сети/API без открытия окна: `python check_api.py`.
- Если `check_api.py` ругается на доступ к soundcloud.com — сайт недоступен
  из твоей сети, поможет VPN.

## Структура

| Файл | Что делает |
|---|---|
| `main.py` | вход, QApplication, «пробел» = плей/пауза, эффекты окна, AppUserModelID |
| `window_effects.py` | стеклянные эффекты окна (ctypes, Win10/11) |
| `mainwindow.py` | сайдбар, поиск, стек страниц, история навигации |
| `pages.py` | страницы: поиск, артист, плейлист, медиатека, недавно, полноэкранный плеер, cava |
| `widgets.py` | обложки, строки списков, слайдер, нижняя панель плеера |
| `player.py` | очередь + QMediaPlayer |
| `sc_api.py` | неофициальный web-API SoundCloud + добыча client_id |
| `storage.py` | лайки и история (JSON) |
| `common.py` | фоновые задачи, картинки, модель Track |
| `theme.py` | стеклянная QSS-тема (rgba) |
| `appicons.py` | векторные иконки (QPainter) |
| `make_icon.py` | генератор icon.ico |

## Известные ограничения

- Нет входа в аккаунт: лайки локальные, у артистов видно только официальную
  статистику.
- client_id SoundCloud периодически меняется — приложение обновляет его само;
  при странных ошибках удали `%APPDATA%\SCClient\client_id.json`.
- Треки go+ (только по подписке) не играют.
- Это неофициальный клиент, не аффилированный со SoundCloud. Никакой
  аффилиации нет; все торговые марки принадлежат их владельцам.
